# Java Programs

A collection of Java programs organized into 16 core Java concepts.

## Topics

1. Java Basics
2. Operators
3. Conditional Statements
4. Loops
5. Arrays
6. Strings
7. Methods
8. Object-Oriented Programming
9. Inheritance
10. Polymorphism
11. Abstraction
12. Encapsulation
13. Exception Handling
14. Collections Framework
15. File Handling
16. Multithreading

## How to Run

```bash
javac FileName.java
java ClassName
```

Each program is independent unless otherwise noted.
